2. Udgiv via GitHub ↗

Ingen ændringer.

Vælg data.js i samme mappe som siden, når du gemmer. Hvis din browser downloader filen, skal du erstatte den eksisterende data.js med den nye. Genindlæs derefter siden.

Sådan opdaterer du hjemmesiden: Gem eller download data.js. Vælg derefter »Udgiv via GitHub«, upload den nye data.js og vælg »Commit changes«. GitHub kræver dit login og adgang til hjemmesidens repository. Opdateringen kommer på hjemmesiden, når GitHub har udgivet ændringen.
